# Customize appearance

Appearance settings change readability and presentation, not your games or server connections.

## Change the look

1. Open **Settings → Appearance**.
2. Select a wallpaper or text color with the directional pad and `X`, or tap the option.
3. Turn **Animated wallpaper** on or off with `X` or a tap.

Changes save automatically. In a platform library, `Triangle` switches grid/list/carousel and saves that choice too.

## What the settings do

| INI setting | Purpose / values |
| --- | --- |
| `ui_wallpaper` | Background: `dark-blue`, `violet`, `blue-waves`, or `light-blue`. |
| `ui_text_color` | Text contrast: `white`, `light`, `dark`, or `black`. Use darker text on a light background. |
| `ui_wallpaper_animated` | `1` enables continuous wallpaper drift; `0` stops it. |
| `active_view` | Saved game layout: `grid`, `list`, or `carousel`. |
| `active_theme` | Theme bundle; leave `default` unless you have installed a compatible alternative. |

Prefer the UI for these settings. For manual edits, close VitaShelf, edit `ux0:data/vitashelflauncher/config.ini`, then relaunch.
